# 🛰️ Подписка «antygravity»

Моя сборная подписка со всеми серверами.

## 📥 Как добавить подписку (быстрый способ)

1. Открой клиент (v2rayNG / v2rayTun / Streisand / Hiddify).
2. Зайди в **Подписки** (Subscriptions) → **Добавить**.
3. Вставь этот URL:

```
https://raw.githubusercontent.com/zaigraevstepan7-afk/Fuckyou/claude/vpn-server-config-y9rpro/antygravity/subscription.txt
```

4. Назови подписку `antygravity` → сохрани → нажми **Обновить**.
5. В списке появятся серверы 👇
