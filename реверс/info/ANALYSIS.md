# Что это за приложение и что оно делает

## Вывод

Это **«Zenin External»** — **чит-лоадер (мод-меню / cheat loader) для игры**, замаскированный
под Reddit. Приложение само по себе не Reddit: настоящее имя в интерфейсе — *Zenin External*,
а имя пакета `com.reddit.frontpage` подставлено для маскировки/обхода детекта.

Приложение по лицензионному ключу авторизует пользователя и загружает в игру читы
(ESP/aim/мод-функции) через конфиги `.cfg`, работая в **root-режиме**.

## На чём основан вывод (прямые строки из APK)

| Строка из ресурсов | Что означает |
|--------------------|--------------|
| `Zenin External` | Настоящее название приложения |
| `Loader runs in root mode. Configs are managed in /sdcard/Zenin/cfg/.` | Это **лоадер**, работает с **root**, конфиги в `/sdcard/Zenin/cfg/` |
| `Key format must be: ZE-********` | Доступ по **лицензионному ключу** формата `ZE-xxxxxxxx` |
| `Authorization`, `Enter key`, `Invalid key`, `Error: invalid` | Экран **авторизации по ключу** (онлайн-проверка) |
| `Safe mode` | Режим «безопасной» работы (снижение риска бана) |
| `Add config`, `Add .cfg`, `Configs`, `Delete config?`, `Config renamed`, `Importing...` | **Менеджер конфигов читов** (`.cfg`) — добавить/импортировать/удалить/переименовать |

## Как это работает (реконструкция логики)

1. **Запуск → авторизация.** `MainActivity` показывает поле ввода ключа
   (`TextInputEditText`), переключатели (`Safe mode` и др.), слайдер и кнопку.
   Ключ `ZE-********` отправляется на сервер для проверки.
   - В нативной либе видны `HttpURLConnection`/`HttpsURLConnection`,
     `X509TrustManager`/`TrustManager` (свой/ослабленный TLS-pinning),
     `javax.crypto.spec.SecretKeySpec` — т.е. **онлайн-валидация ключа с шифрованием трафика**.
2. **Загрузка читов.** После успешной авторизации лоадер в **root-режиме**
   внедряет читы в целевую игру. Имя нативной либы — **`libZeninCPP.so`**.
3. **Конфиги.** `ConfigsActivity` управляет файлами `.cfg` в `/sdcard/Zenin/cfg/`:
   импорт через системный файл-пикер (`ActivityResultLauncher` + `Uri`),
   список (`RecyclerView`), добавление/удаление/переименование, дата изменения.

## Защита и обфускация (почему «глубже» только динамикой)

- **Dex2C / VMP.** Java-методы ключевых классов объявлены `native` — реальный код
  скомпилирован в `libZeninCPP.so` и регистрируется через
  `ZLoader.registerNativesForClass()` + `JNI_OnLoad` (нет символов `Java_*`).
- **Шифрование строк** (таблицы `short[]` + нативные дешифраторы) — поэтому в
  открытом виде нет ни сервера авторизации, ни целевого пакета игры.
- **Обфускация ресурсов:** 864 бинарных XML вынесены в каталог с именем из
  арабской графики (`ۦ/…`), а имена строк/ресурсов затёрты (`APKTOOL_DUPLICATE_*`).
- **Переподпись тестовым ключом AOSP** (`android@android.com`) — не из Google Play.

## Признаки риска

- Запрашивает `MANAGE_EXTERNAL_STORAGE`, `QUERY_ALL_PACKAGES` (сканирование
  установленных приложений — поиск игры), `DUMP`, доступ к хранилищу.
- Требует **root** и внедряется в чужой процесс — типичное поведение читов.
- Платный доступ по ключу `ZE-*` с онлайн-сервером (модель «подписка на чит»).
- Маскировка под Reddit + сокрытие логики в нативе = намеренный обход детекта.

> Использование таких лоадеров нарушает правила игр (бан аккаунта/устройства),
> а установка модифицированного APK из неофициального источника несёт риск
> вредоносного кода. Разбор сделан в исследовательских целях.
