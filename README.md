# Doka Камера 1.3.13 — русификация (reverse + localize + rebuild)

Полная русификация Android-приложения **Doka相机 (Doka Камера)** 1.3.13
(`com.ydgn.doka`, versionCode 44, minSdk 29, targetSdk 34). Реверс через apktool,
перевод интерфейса с китайского на русский в ресурсах **и** в коде, обратная
сборка и подпись.

## Что сделано

- **Строковые ресурсы** — переведено **387** строк приложения в
  `res/values/strings.xml` (+ переопределения в `values-zh-rCN/-rTW/-rHK/-zh/-ja`).
  Итог: 11 671 кириллических символов, из иероглифов остался только номер
  ICP-лицензии (юридический реквизит, трогать нельзя).
- **Зашитый в код текст** — переведено **154** уникальных строки (164 вхождения)
  в UI-классах smali: названия и описания плёночных фильтров/сцен (`Y/b.smali`,
  131 строка), экран подписки, тосты WeChat, удаление аккаунта, подсказки ИИ-компоновки.
- **Название приложения**: `Doka相机` → **`Doka Камера`**.
- Терминология: `AI 构图` → «ИИ-компоновка», `AI 滤镜` → «ИИ-фильтр»,
  `滤镜` → «фильтр», `水平仪` → «Уровень», `辅助线` → «Сетка», `底片` → «негатив».

### Что намеренно НЕ переведено (чтобы не сломать функционал)

- **Логика-строки в коде** — токены разбора цены в `VipPurchaseActivity`
  (`约`, `/天`, `每天`): передаются в `contains()`-сравнения серверной строки цены.
  Их перевод сломал бы отображение цены.
- **SDK-диагностика** (`com/umeng/**`, `com/efs/**` и др.) — внутренние логи, не UI.
- **Имена устройств** (`小米`/Xiaomi, `华为`/Huawei) — используются для сравнений.
- **Шейдеры GLSL** (комментарии), **IDN-регэксп** (`PatternsCompat`), **URL, ключи, email,
  реквизиты компании/ICP** — оставлены как есть.
- Текст, приходящий с сервера, и строки внутри нативных `.so` — вне зоны правки.

## Как пересобрать

```bash
tools/build.sh /путь/к/оригинальному/Doka_1.3.13.apk
# результат: ./Doka_ru.apk (подписан ключом .build/doka.keystore)
```

Скрипт: скачивает apktool 2.12.1 (Maven Central), декодирует APK, чинит
приватные ссылки фреймворка в `values-v31/-v34` (Material3 dynamic colors →
префикс `@*android:`, иначе aapt2 не линкует), применяет переводы
(`tools/apply_res.py`, `tools/apply_code.py`), собирает, выравнивает и подписывает.

Инструменты: `apktool 2.12+`, `aapt2`, `zipalign`, `apksigner`, `keytool`, JDK 17+.
apktool 2.7 (из apt) НЕ подходит — не собирает ресурсы с именами через `$`.

## Файлы

- `tools/translations_res.json` — словарь `имя_ресурса → русский` (387).
- `tools/translations_code.json` — словарь `китайский_литерал → русский` (154).
- `tools/translations_review.tsv` — все переводы для ревью (zh/ключ → ru).
- `tools/apply_res.py`, `tools/apply_code.py` — аппликаторы (уважают `DECODED_DIR`).
- `tools/build.sh` — полный воспроизводимый конвейер.
- `localized/values/strings.xml` — итоговый переведённый файл ресурсов (референс).

## ВАЖНО: подпись и ограничения

- **Оригинальную подпись воспроизвести нельзя.** В APK хранится только публичный
  сертификат разработчика; приватный ключ есть только у него и не восстановим.
  Поэтому сборка подписана **новым самоподписанным ключом** (`doka.keystore`).
  Схема подписи v3 проходит проверку для minSdk 29 (Android 10+), APK
  устанавливается как **отдельное** приложение (не обновит официальное).
- **Вход/шеринг через WeChat**, скорее всего, не сработают: WeChat OpenSDK сверяет
  подпись приложения с зарегистрированной у разработчика.
- **Анти-тамперинг**: в APK есть `libdoka_security.so` (см. строку `security_block_*` —
  «Среда устройства не прошла проверку безопасности»). Модифицированный+переподписанный
  APK может быть задетектирован и заблокирован при запуске. Это проверяется только
  на реальном устройстве; обойти без реверса нативной библиотеки нельзя.

## Проверка

- `apksigner verify --min-sdk-version 29 Doka_ru.apk` — подпись валидна (v3).
- `aapt2 dump badging Doka_ru.apk` — `application-label: 'Doka Камера'`, пакет/версии не изменены.
- Установка на устройство/эмулятор arm64-v8a (API 29+) — финальная проверка запуска,
  анти-тамперинга и работы камеры/фильтров.
