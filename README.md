# 🇳🇱 Стёпка топ а Никита лох

Мой VLESS + Reality конфиг.

## Как подключиться

1. Установи любой клиент с поддержкой VLESS/Reality (v2rayNG, Hiddify, Nekoray, Streisand и т.п.)
2. Скопируй ссылку из [`vpn-config.txt`](./vpn-config.txt)
3. Импортируй её в клиент (обычно «Добавить из буфера обмена» / «Import from clipboard»)
4. Подключайся 🚀
