# 🌐 Free working VPN subscription for Happ (real-tested, auto-updating)

Самообновляющаяся подписка с **реально работающими** бесплатными серверами для
приложения [**Happ**](https://www.happ.su): 1 сервер **AUTO** (самый быстрый) +
ещё 10. Каждый сервер **проверяется по-настоящему** — через ядро xray
поднимается соединение и прогоняется HTTP-запрос. Мёртвые серверы, неверные
SNI/UUID и битый TLS отсеиваются, поэтому **ошибки «TLS handshake» при импорте
больше нет**.

> Подписку каждые 6 часов пересобирает GitHub Action, поэтому ссылка всегда
> отдаёт живые серверы. Каждый сервер помечен его **реальной страной выхода**.

## ⚠️ Честно про «Канаду»

Задача была про Канаду, но **бесплатных серверов с реальным выходом именно в
Канаде в публичных списках сейчас практически нет**: то, что помечают «Canada»,
на деле — CDN-фронты, выходящие во Франции/Германии, или мёртвые узлы (именно они
и давали ошибку TLS). Проверка это подтвердила: из сотен «канадских по фронту»
кандидатов ни один не выходит в Канаде.

Поэтому здесь — **лучшие реально работающие** серверы (Канада в приоритете, если
появится; иначе — ближайшие/быстрейшие), честно помеченные по настоящей стране.
Метки вроде `🇫🇷 France · AUTO` показывают, где сервер **на самом деле**.

👉 Нужен **гарантированный канадский** выход — подними свой бесплатный сервер в
Канаде (Oracle Cloud Always Free, регион Торонто/Монреаль). Скажи — дам готовый
скрипт развёртывания VLESS+Reality и конфиг для Happ.

## 🚀 Как подключить в Happ

1. Открой файл **`canada.txt`** → **Raw** → скопируй ссылку:

   ```
   https://raw.githubusercontent.com/zaigraevstepan7-afk/Fuckyou/claude/vpn-app-development-4iygit/canada.txt
   ```

2. В **Happ** → **Подписки** → **＋ Добавить** → вставь ссылку → **Сохранить** →
   **Обновить**.
3. Появятся 11 серверов: **AUTO** + 10 пронумерованных (с флагом реальной страны
   и задержкой в мс).
4. Включи в Happ режим **Auto / URL-test** (сам выберет быстрейший) или выбери
   сервер **AUTO** вручную.

> Если клиент требует **base64** — используй файл **`canada_base64.txt`**.

## 🔁 Обновление

- **Автоматически:** `.github/workflows/refresh.yml` — cron каждые 6 ч + ручной
  запуск (**Actions → Run workflow**). Экшен ставит `xray-knife`, пересобирает
  список и коммитит. Happ подтянет обновление при «Обновить подписку».
- **Локально:**

  ```bash
  # один раз: поставить валидатор (нужен Go)
  go install github.com/lilendian0x00/xray-knife/v3@latest
  export PATH="$PATH:$(go env GOPATH)/bin"

  python3 generate_sub.py      # перезапишет canada.txt / canada_base64.txt
  ```

## ⚙️ Как это работает (`generate_sub.py`)

1. Скачивает публичные списки бесплатных конфигов из `sources.txt`
   (auto-decode base64; ретраи при обрывах). Протоколы `vless`/`vmess`/`trojan`/`ss`.
2. Извлекает `host:port`, дедуплицирует.
3. **Быстрый TCP-префильтр** (asyncio) — отсеивает явно мёртвые адреса.
4. **Настоящая валидация** через [`xray-knife`](https://github.com/lilendian0x00/xray-knife):
   реально проксирует трафик, замеряет задержку и определяет **истинную страну
   выхода** (через `/cdn-cgi/trace`).
5. Ранжирование: Канада → США → прочие известные страны → неизвестные
   (CDN-фронты); внутри группы — по возрастанию задержки. Берётся 11, №1 = AUTO.
6. Пишет `canada.txt` и `canada_base64.txt`.

Источники правятся в `sources.txt` (по одному URL в строке; недоступные
пропускаются автоматически).

## 📋 Требования

- **Python 3** (только стандартная библиотека).
- **`xray-knife`** в `PATH` (или переменная `XRAY_KNIFE=/путь/к/xray-knife`).
  Ставится одной командой `go install …` (см. выше). В GitHub Action ставится сам.
