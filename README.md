# Наша ИИ — русскоязычный чат-бот на своём GPT (с нуля)

Это **полностью наша** языковая модель: собственный GPT-трансформер, обученный
**с нуля** (случайная инициализация весов) на русском корпусе. Мы **не дообучаем**
и не берём ничьи предобученные веса — PyTorch используется только как библиотека
тензоров, а всё, что модель «знает», выучено из наших данных.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `model.py` | Наш GPT: эмбеддинги, causal self-attention, MLP, блоки, LM-head |
| `tokenizer.py` | Наш BPE-токенизатор, словарь учится из нашего корпуса (+ char-level fallback) |
| `config.py` | Пресеты размеров модели, включая `8B` (см. ниже) |
| `data/download_data.py` | Скачивает русский корпус: Википедия + инструкции + диалоги |
| `data/prepare.py` | Обучает токенизатор и токенизирует корпус в `train.bin`/`val.bin` |
| `train.py` | Обучение на CPU с чекпоинтами и возобновлением |
| `chat.py` | Чат с моделью (наш чат-бот) |
| `sample.py` | Генерация сырого текста |

## Как воспроизвести

```bash
pip install -r requirements.txt

# 1. Скачать данные (регулируется --wiki_mb / --chat_mb)
python data/download_data.py --wiki_mb 90 --chat_mb 50

# 2. Обучить наш токенизатор и токенизировать корпус
python data/prepare.py --vocab_size 12000

# 3. Обучить модель (чекпоинты в checkpoints/)
python train.py --preset max-quality-cpu          # можно прервать и продолжить: --resume

# 4. Пообщаться
python chat.py
python sample.py --prompt "Москва — это"
```

## Данные

Русский корпус из трёх публичных источников (HuggingFace), в микс:
- **wikimedia/wikipedia (ru)** — беглость и грамматика;
- **d0rj/alpaca-cleaned-ru** — инструкция → ответ;
- **Den4ikAI/russian_dialogues_2** — многоходовые диалоги.

Инструкции и диалоги оборачиваются в chat-шаблон:
```
<|user|>вопрос<|assistant|>ответ<|endoftext|>
```

## Пресеты модели (`python config.py`)

- `debug` — крошечная, для проверки, что всё учится;
- `max-quality-cpu` — **то, что реально обучаем здесь** (~14M параметров, подобрано
  под скорость этого CPU-сервера);
- `8B` — **8 миллиардов параметров**, та же наша архитектура, только крупнее.

### Про «8 миллиардов»

Пресет `8B` заложен в код честно, но **обучить его на этом сервере физически нельзя**:
только веса в fp32 = 32 ГБ (а RAM здесь 15 ГБ), для обучения нужно ~128 ГБ и тысячи
GPU-часов. Этот пресет — чтобы запустить нашу же архитектуру на GPU-железе:
```bash
python train.py --preset 8B      # требует GPU и много RAM
```

## Честные ограничения

Сервер — **4 CPU-ядра, 15 ГБ RAM, без GPU**. Поэтому модель небольшая. «Максимум
качества» здесь означает связный русский язык и узнаваемый диалоговый формат, но
**не** энциклопедическую точность больших LLM. Это фундаментальный предел обучения
языковой модели с нуля без GPU.

## Метрики обучения

_Заполняется после обучения:_ размер модели, число токенов, итоговый val-loss,
время обучения и пример диалога.
