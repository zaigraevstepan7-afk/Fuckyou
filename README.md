# 🇨🇦 Free Canada VPN subscription for Happ

Готовая **самообновляющаяся** подписка с бесплатными **канадскими** серверами для
приложения [**Happ**](https://www.happ.su): один сервер **AUTO** (самый быстрый) +
ещё 10 серверов. Все серверы **реально проверяются по TCP** на доступность перед
попаданием в список, а страна определяется по GeoIP (реальные канадские
дата-центры, а не CDN-anycast).

> Подписку каждые 6 часов пересобирает GitHub Action, поэтому ссылка всегда
> отдаёт свежие живые серверы.

## 🚀 Как подключить в Happ

1. Открой файл **`canada.txt`** в этом репозитории → нажми **Raw** → скопируй
   ссылку из адресной строки. Она выглядит так:

   ```
   https://raw.githubusercontent.com/zaigraevstepan7-afk/fuckyou/claude/vpn-app-development-4iygit/canada.txt
   ```

2. В приложении **Happ** → вкладка **Подписки/Subscriptions** → **＋ Добавить** →
   вставь эту ссылку → **Сохранить** → **Обновить**.
3. Появятся 11 серверов: **🇨🇦 Canada · AUTO** и **🇨🇦 Canada-01 … Canada-10**.
4. Включи в Happ встроенный режим **Auto / URL-test** — он сам пингует все серверы
   и держит подключение через самый быстрый. Либо просто выбери сервер **AUTO**.

> Если какой-то клиент требует **base64**-подписку — используй файл
> **`canada_base64.txt`** тем же способом.

## 🔁 Обновление

- **Автоматически:** GitHub Action `.github/workflows/refresh.yml` запускается по
  расписанию (каждые 6 ч) и вручную (вкладка **Actions → Run workflow**). Happ
  сам подтянет обновлённый список при «Обновить подписку».
- **Вручную/локально:**

  ```bash
  python3 generate_sub.py
  ```

  Нужен только Python 3 (без сторонних зависимостей). Скрипт перезапишет
  `canada.txt` и `canada_base64.txt`.

## ⚙️ Как это работает (`generate_sub.py`)

1. Скачивает публичные списки бесплатных конфигов из `sources.txt`
   (auto-decode base64), поддержка `vless` / `vmess` / `trojan` / `ss`.
2. Извлекает `host:port`, дедуплицирует.
3. **TCP-проверка** каждого сервера (asyncio, таймаут 3 с) — в список идут только
   те, кто реально принял соединение; замеряется задержка.
4. **GeoIP** живых хостов через `ip-api.com/batch` → страна + ASN.
5. Отбор: сначала настоящие канадские дата-центровые серверы (не CDN), затем, при
   нехватке до 11, — быстрейшие соседние (США). Дедуп по IP, сортировка по задержке.
6. Пишет `canada.txt` (plaintext) и `canada_base64.txt`.

Добавить/убрать источники — правь `sources.txt` (по одному URL в строке;
недоступные пропускаются автоматически).

## ⚠️ Дисклеймер

Серверы берутся из **публичных бесплатных** списков в интернете. Они эфемерны
(могут отвалиться в любой момент — поэтому и авто-обновление каждые 6 часов),
не гарантируют скорость, приватность или аптайм. Не используй их для
чувствительного трафика. Проект — для образовательных целей и обхода блокировок;
соблюдай законы своей юрисдикции.
