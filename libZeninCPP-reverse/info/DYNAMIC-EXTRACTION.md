# Извлечение секретов: почему статика упирается и что делает Frida

## Итог статического анализа строк
- Дешифратор строк Java-уровня — простой **XOR**:
  `char[i] = short[start+i] ^ key` (см. `C1122.m2840` и 62 однотипных метода).
- НО данные `short[]` отдают **нативные геттеры** (`m4281()` и т.п.) — они
  зашифрованы внутри `libZeninCPP.so` и собираются в рантайме.
- В `MainActivity` (где сеть, авторизация, крипто) — **0** Java-вызовов
  дешифровки: весь чувствительный код нативный, строки в Java не всплывают.
- В нативе **нет чистой функции-дешифратора** (искал XOR-петли — не найдены):
  расшифровка вплетена в VM-диспетчер Dex2C. Признаки: **62 371** косвенный
  вызов через таблицу функций `JNIEnv` (offset-вызовы `(*env + 0xNN)(…)`),
  строки уходят в JVM через `NewStringUTF` по offset (имя Ghidra не разрешает).

**Вывод:** адрес сервера авторизации, целевой пакет игры и AES-ключи статически
из этого APK извлечь нельзя — нужен запуск под инструментацией.

## Решение — Frida (папка `../frida/`)
Перехват на границе JNI/Java, которую нативный код обойти не может:

| Что перехватываем | Где | Что получаем |
|---|---|---|
| `libart!NewStringUTF`, `GetStringUTFChars` | нативный → JVM | расшифрованные строки из натива |
| `libart!RegisterNatives` | JNI | карта «нативный адрес ↔ Java-метод» (231 натив) |
| `java.net.URL`, `HttpURLConnection` | Java API | **адрес сервера авторизации**, заголовки, тело |
| `javax.crypto.Cipher`/`SecretKeySpec` | Java API | **AES-ключи/IV**, вход/выход |
| `PackageManager`/`ComponentName`/`Intent` | Java API | **целевой пакет игры** |
| XOR-декодеры `m####(short[]…)` | Java | строки, идущие через Java |

Скрипты:
- `frida/dump-secrets.js` — основной дамп (все хуки выше).
- `frida/anti-debug-bypass.js` — обход типовой анти-отладки Dex2C.
- `frida/run.py` — раннер (спавн + запись `dump.log`).

### Порядок действий (на рутованном устройстве/эмуляторе)
1. Поднять `frida-server` нужной арки (в APK есть `arm64-v8a` и `x86_64`).
2. `frida -U -f com.reddit.frontpage -l frida/anti-debug-bypass.js -l frida/dump-secrets.js --no-pause`
3. В логе сразу появятся `[NET][URL]`, `[NET][header]`, `[CRYPTO][key]`,
   `[PKG][…]`, `[JNI][NewStringUTF]` — это и есть сервер, ключи и целевой пакет.
4. (Опционально) Найти offset нативного дешифратора в Ghidra и дохукать его в
   `dump-secrets.js` (`waitForLib`) — тогда дампятся вообще все строки.
